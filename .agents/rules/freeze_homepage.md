# IMMUTABLE HOMEPAGE COMPONENT RULE

The following frontend files contain the frozen, pixel-perfect ConfirmTkt Homepage layout and styling. 
They must NOT be edited, overwritten, or modified under any circumstances during future feature work unless the user explicitly requests changes to the Homepage itself:

- `platform/frontend/src/pages/HomePage.jsx`
- `platform/frontend/src/components/Header.jsx`
- `platform/frontend/src/components/SearchWidget.jsx`
- `platform/frontend/src/components/InfoSections.jsx`
- `platform/frontend/src/components/Footer.jsx`

All future development (Search Results, Coach Seat Selection, Booking Drawers, Payment Gateway, Admin Dashboard) MUST take place in new, separate component/page files.
