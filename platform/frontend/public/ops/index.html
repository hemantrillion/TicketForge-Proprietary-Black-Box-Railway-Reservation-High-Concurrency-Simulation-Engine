Black-Box Content Protection & Security Policy

1. Standalone Black-Box Architecture: TicketForge runs as an isolated service. Frontend/backend source code is never exposed or distributed to third-party clients.

2. Anti-Scraping Protection: Text selection (user-select: none), right-click context menu blocking, and inspect shortcut locks are globally enforced across consumer facing routes.

3. OPS Control Isolation: The OPS portal resides in a distinct, decoupled folder structure outside the core platform source directory.
